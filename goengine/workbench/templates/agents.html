Run Extraction Locally

A browser can't run anything on your own computer -- that's a hard security boundary, not a missing feature. Pick a department below to get the exact commands to run in a terminal on the machine with unblocked access to government sites. That machine downloads and OCRs the documents, then sync pushes the results back here automatically.

One-time local setup (do this once per machine)
  1. Clone this repository and install dependencies: pip install -r requirements.txt
  2. Install Tesseract OCR (with English + Tamil language packs) on that machine.
  3. Generate an agent key above, then set it as an environment variable on that local machine (not on Render): THIRDEYE_AGENT_KEY=<the key you copied>
